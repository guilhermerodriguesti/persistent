1. Introdução à Informática Forense

Definição

A Informática Forense (ou Digital Forensics) é a aplicação de princípios científicos e técnicos à preservação, coleta, validação, identificação, análise, interpretação, documentação e apresentação de evidências digitais, de forma que sejam admissíveis em processos judiciais.

Princípios Fundamentais
  • Integridade: Evidências não podem ser alteradas
  • Cadeia de Custódia: Rastreabilidade completa da evidência
  • Originalidade: Preservação do estado original
  • Reprodutibilidade: Processos podem ser replicados

2. Ordem de Volatilidade (RFC 3227)

Regra de Ouro

Evidências mais voláteis devem ser coletadas primeiro! A ordem é crítica para evitar perda de dados.

VOCÊ
"Volatilidade: O que Cai, Você Coleta"
Volátil → Primeiro
Ordem → Cronológica
Coleta → Imediata
Ênfase → Prioridade
Ordem Evidência Volatilidade Exemplo
1º Registradores da CPU Extrema EAX, EBX, flags do processador
2º Cache da CPU Muito Alta L1, L2, L3 cache
3º Memória RAM Alta Processos em execução, senhas
4º Tabelas de Roteamento Média-Alta ARP cache, tabela de roteamento
5º Estado da Rede Média Conexões ativas, portas abertas
6º Logs do Sistema Média Event Viewer, syslog
7º Arquivos de Configuração Baixa /etc, Registry
8º Armazenamento em Disco Baixa HD, SSD, USB
9º Backups e Mídia Removível Muito Baixa Fitas, CDs, DVDs
Erros Comuns
  • Desligar o sistema antes de coletar a RAM
  • Ignorar cache e registradores
  • Coletar disco antes da memória
  • Alterar timestamps durante a coleta

    Extração da evidência com técnicas forenses

    Embalagem adequada para preservação e transporte

    Movimentação segura com registro de responsáveis

    Formalização da entrega no laboratório forense

    Destruição autorizada quando não mais necessária
Quebra da Cadeia de Custódia

Qualquer quebra na cadeia de custódia pode tornar a evidência inadmissível em juízo. Documentação completa é essencial.

4. Imagem Forense Bit-a-Bit

Definição

Cópia exata e completa de todos os bits de um dispositivo de armazenamento, incluindo espaço não alocado, dados apagados e metadados. É a base da perícia digital.

Formatos de Imagem Forense

Formato Extensão Características Uso
DD .dd, .img Raw, sem metadados Universal, compatível com todas as ferramentas
E01 .E01 Compressão, metadados EnCase, padrão de mercado
AFF .aff, .afd Compressão, criptografia AFF4, open source
DMG .dmg Apple Disk Image macOS forense
Vantagens da Imagem Bit-a-Bit
  • Preserva dados apagados (recuperáveis)
  • Inclui espaço não alocado
  • Mantém timestamps originais
  • Permite análise offline segura
  • Reproduzível e verificável via hash

Comandos Comuns

# Criar imagem DD
dd if=/dev/sdX of=evidencia.dd bs=4M conv=noerror,sync status=progress

# Verificar hash
sha256sum evidencia.dd > evidencia.dd.sha256

# Converter E01 para DD
ewfinfo evidencia.E01
ewfexport -f dd -o evidencia.dd evidencia.E01

5. Write Blocker

Definição

Dispositivo hardware ou software que impede qualquer escrita no disco durante a aquisição da imagem forense, garantindo a integridade da evidência.

Tipos de Write Blocker

  • 🔌
    Hardware Write Blocker
    Dispositivo físico entre o disco e o computador. Mais seguro e confiável.
  • 💻
    Software Write Blocker
    Driver ou software que bloqueia escritas. Menos seguro, pode ser contornado.
Importante

Sempre use hardware write blocker quando possível. Software write blockers podem falhar ou serem desativados pelo sistema operacional.

Ferramentas Comerciais

Ferramenta Tipo Interface
Tableau Hardware IDE, SATA, SCSI, USB
WiebeTech Hardware SATA, USB, FireWire
UltraBlock Hardware SATA, SAS, USB
Linux blockdev Software Comando: blockdev --setro

6. Hash e Integridade de Evidências

Função Hash

Algoritmo matemático que gera um valor fixo (fingerprint) único para um arquivo. Qualquer alteração no arquivo altera o hash completamente.

Algoritmos de Hash

Algoritmo Bits Hexadecimal Segurança Status
MD5 128 32 caracteres Baixa Colisões conhecidas - NÃO usar
SHA-1 160 40 caracteres Média Desuso - colisões demonstradas
SHA-256 256 64 caracteres Alta Padrão recomendado
SHA-512 512 128 caracteres Muito Alta Máxima segurança
Boas Práticas
  • Use SHA-256 ou superior para novas perícias
  • Calcule hash antes e depois da aquisição
  • Documente o hash no laudo pericial
  • Verifique periodicamente integridade de evidências armazenadas

Comandos de Hash

# SHA-256 (Linux/Mac)
sha256sum arquivo.dd

# SHA-256 (Windows PowerShell)
Get-FileHash -Algorithm SHA256 arquivo.dd

# Verificar integridade
sha256sum -c arquivo.dd.sha256

7. Windows Forense

Arquivos e Registros Críticos

  • 📁
    Registry (Registro)
    Configurações do sistema, programas, usuário. Caminho: C:\Windows\System32\config
  • 📝
    Event Logs
    Logs de segurança, sistema, aplicativos. Event Viewer: eventvwr.msc
  • 🗑️
    $Recycle Bin
    Arquivos deletados. Info em $I (metadata) e $R (dados)
  • 🔍
    Prefetch
    Rastreamento de execução de programas. C:\Windows\Prefetch
  • 🕐
    SRUM
    System Resource Usage Monitor - histórico de uso de recursos
  • 🌐
    Amcache.hve
    Cache de aplicações executadas, mesmo após deletar Prefetch

Event IDs Importantes

Event ID Categoria Descrição
4624 Login Login bem-sucedido (conta autenticada)
4625 Login Falha de login (credenciais incorretas)
4634 Logout Logout de conta
4720 Criação Criação de conta de usuário
4726 Deleção Deleção de conta de usuário
4728 Grupo Membro adicionado a grupo com privilégios
4732 Grupo Membro adicionado a grupo local
4740 Bloqueio Conta de usuário bloqueada
1102 Logs Log de segurança limpo/clear
Registry Keys Importantes
  • HKEY_LOCAL_MACHINE\SYSTEM - Configurações do sistema
  • HKEY_LOCAL_MACHINE\SOFTWARE - Programas instalados
  • HKEY_LOCAL_MACHINE\SAM - Contas e senhas (protegido)
  • HKEY_CURRENT_USER\Software - Configurações do usuário
  • HKEY_CURRENT_USER\NTUSER.DAT - Hive do usuário atual

8. Linux Forense

Diretórios e Arquivos Críticos

  • 📁
    /etc/passwd
    Contas de usuários (sem senhas)
  • 🔐
    /etc/shadow
    Hashes de senhas (requer root)
  • 📝
    /var/log/
    Logs do sistema (auth.log, syslog, kern.log)
  • ⚡
    /var/log/wtmp
    Histórico de logins (comando last)
  • 🔒
    /var/log/btmp
    Histórico de falhas de login (comando lastb)
  • 🕐
    /var/log/utmp
    Usuários logados atualmente (comando who)
  • 🗑️
    ~/.bash_history
    Histórico de comandos do usuário
  • 🔗
    /etc/crontab
    Tarefas agendadas (cron jobs)

Comandos Forenses

# Histórico de logins
last -n 50
lastb -n 50

# Usuários atuais
who
w

# Processos em execução
ps aux
ps -ef

# Conexões de rede
netstat -tulpn
ss -tulpn

# Arquivos abertos por processo
lsof -p [PID]

# Arquivos modificados recentemente
find / -mtime -7 -type f

# Verificar SUID/SGID
find / -perm -4000 -o -perm -2000

9. Mobile Forense

Desafios Específicos

Dispositivos móveis apresentam desafios únicos: criptografia por hardware, isolamento de processos, atualizações constantes e proteção contra jailbreak/root.

Métodos de Extração

Método Tipo Dados Complexidade
Lógica Software Dados ativos (contatos, SMS, apps) Baixa
Física Bit-a-bit Partições completas, dados apagados Média
JTAG Hardware Dump da memória via test points Alta
Chip-Off Hardware Leitura direta do chip de memória Muito Alta
Ordem de Preferência

Sempre tente extração lógica primeiro (menos invasiva). Se não for suficiente, avance para física, JTAG e finalmente Chip-Off (último recurso).

Android vs iOS

Característica Android iOS
Criptografia FDE (Full Disk Encryption) Data Protection (hardware)
Arquitetura Linux-based, open source Proprietária, closed source
Root Possível (varia por fabricante) Muito difícil (checkm8)
Extração Adb, ferramentas variadas Requer ferramentas especializadas
Logs /log, /data/log syslog, crash logs

10. Análise de Logs

Importância dos Logs

Logs são registros de eventos do sistema que fornecem linha do tempo de atividades, essenciais para reconstrução de incidentes e atribuição de responsabilidade.

Tipos de Logs

  • 🔒
    Security Logs
    Autenticação, autorização, acessos
  • ⚙️
    System Logs
    Eventos do sistema operacional
  • 📱
    Application Logs
    Eventos de programas e serviços
  • 🌐
    Network Logs
    Firewall, proxy, roteador, IDS/IPS
  • 🔍
    Antivirus/EDR Logs
    Detecções de malware, quarentenas
Técnicas de Análise
  • Timeline: Ordenar eventos cronologicamente
  • Correlação: Cruzar informações de diferentes fontes
  • Filtragem: Isolar eventos relevantes
  • Padrões: Identificar comportamentos anômalos
  • Baseline: Comparar com comportamento normal

11. Recuperação de Dados

Carving

Técnica de recuperação de dados baseada em identificação de cabeçalhos de arquivos (file signatures) em espaço não alocado do disco, independentemente do sistema de arquivos.

File Signatures Comuns

Tipo Extensão Header (Hex) Footer (Hex)
JPEG .jpg, .jpeg FF D8 FF FF D9
PNG .png 89 50 4E 47 49 45 4E 44 AE 42 60 82
PDF .pdf 25 50 44 46 25 25 45 4F 46
ZIP .zip 50 4B 03 04 50 4B 05 06
DOCX .docx 50 4B 03 04 50 4B 05 06
MPEG .mpg, .mpeg 00 00 01 BA 00 00 01 B7

NTFS e MFT

  • 📋
    MFT (Master File Table)
    "Índice" do NTFS - metadados de todos os arquivos
  • 🗑️
    Deleção NTFS
    Arquivo marcado como "deletado" no MFT, dados permanecem
  • ✏️
    $USNJrnl
    Journal de alterações NTFS (Change Journal)
  • 🔍
    $LogFile
    Log transacional do NTFS
SSD vs HDD

Em SSDs com TRIM ativado, dados deletados podem ser sobrescritos automaticamente. Recuperação em SSDs é mais difícil que em HDDs magnéticos.

12. Esteganografia Forense

Definição

Técnica de ocultar informações dentro de outras informações (ex: mensagem em imagem) de forma que a existência da informação oculta seja imperceptível.

Técnicas Comuns

  • 🖼️
    LSB (Least Significant Bit)
    Modificação dos bits menos significativos de pixels em imagens
  • 🎵
    Audio Steganography
    Ocultação em arquivos de áudio (MP3, WAV)
  • 📄
    Document Steganography
    Ocultação em metadados ou whitespace de documentos
  • 🌐
    Network Steganography
    Ocultação em headers de protocolos de rede

Ferramentas de Análise

Ferramenta Tipo Uso
Stegdetect Open Source Detecta steganografia em imagens JPEG
Steghide Open Source Extração de dados ocultos
Outguess Open Source Análise de esteganografia
StegSecret Comercial Suite completa de análise

13. Criptografia Forense

Desafios

Criptografia forte pode tornar evidências inacessíveis. Peritos precisam identificar e contornar proteções criptográficas quando possível.

Tipos de Criptografia

Tipo Chaves Exemplo Uso Comum
Simétrica 1 chave (secreta) AES, 3DES Criptografia de disco (BitLocker)
Assimétrica 2 chaves (pública/privada) RSA, ECC Assinaturas, PGP
Hash Sem chave (one-way) SHA-256, MD5 Integridade, senhas
Contornando Criptografia
  • Key Recovery: Buscar chaves em memória, swap, hibernação
  • Weak Keys: Tentar força bruta em chaves fracas
  • Side-Channel: Análise de consumo de energia, timing
  • Backdoors: Verificar vulnerabilidades conhecidas
  • Legal: Ordem judicial para entrega de chaves

14. Network Forense

Definição

Análise de tráfego de rede para identificar atividades maliciosas, reconstruir incidentes e atribuir responsabilidade. Envolve captura e análise de pacotes.

Fontes de Evidência de Rede

  • 📦
    PCAP (Packet Capture)
    Captura completa de pacotes de rede
  • 🔥
    Firewall Logs
    Registros de conexões bloqueadas/permitidas
  • 🌐
    Proxy Logs
    HTTP/HTTPS requests, URLs acessadas
  • 📡
    Router/Switch Logs
    Conexões, ARP, routing
  • 🔍
    DNS Logs
    Resoluções de nomes, queries DNS
  • ⚠️
    IDS/IPS Logs
    Alertas de intrusão, assinaturas ativadas

Ferramentas de Análise

Ferramenta Tipo Uso Principal
Wireshark Open Source Análise profunda de PCAP
Tcpdump CLI Captura e filtragem de pacotes
NetworkMiner Open Source Extração de arquivos, hosts
Snort IDS/IPS Detecção em tempo real
Zeek (Bro) NSM Monitoramento de segurança de rede

15. Análise de Malware

Tipos de Análise

Tipo Descrição Ferramentas Risco
Estática Análise sem executar (código, strings, PE) IDA Pro, Ghidra, Strings Nenhum
Dinâmica Análise durante execução (comportamento) Sandbox, Process Monitor, Wireshark Médio
Híbrida Combinação de estática + dinâmica Várias ferramentas Médio
Memory Análise de dump de memória RAM Volatility, Rekall Baixo
Indicadores de Comprometimento (IOCs)
  • Hashes: MD5, SHA-1, SHA-256 de arquivos maliciosos
  • IPs: Endereços IP de C2 (Command & Control)
  • Domínios: Domínios usados para comunicação
  • URLs: URLs de download, phishing
  • Email: Endereços usados em campanhas
  • Registry Keys: Chaves criadas/modificadas
  • Filenames: Nomes de arquivos maliciosos
